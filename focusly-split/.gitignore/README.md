# Focusly

A to-do app with dashboard stats, categories, priorities, due dates, search, sorting, and light/dark themes.

## Files
- `index.html`: page structure
- `style.css`: layout, themes, responsive rules, and animations
- `app.js`: task logic, storage, filtering, sorting, and rendering

## Run it
Open `index.html` in a modern browser. For a local server (for example, VS Code Live Server), open the folder and start Live Server from `index.html`.

Tasks are saved in this browser's localStorage under `taskflow.v1`, so they are not synced across devices.
